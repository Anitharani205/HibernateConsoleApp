Microfinance Loan Application :

This is a Java console application to manage microfinance loans using Hibernate and Oracle DB.
It allows registering borrowers, creating loans, and adding loan installments.
IDs for borrowers, loans, and installments are generated using Oracle sequences.
The app uses Hibernate for ORM and handles transactions automatically.
Run the application after creating the required tables and sequences in Oracle.
All operations and errors are logged in the console for easy tracking.
